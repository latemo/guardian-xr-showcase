# GUARDIAN XR | 라이더 온디바이스 HUD 프로토타입

라이더 영상의 객체 검출·단안 깊이·접근 징후를 결합해, 모든 객체를 나열하는 대신 **위험 관련성이 높은 정보의 HUD 표시 우선순위**를 판단하고 음성으로 안내하는 프로토타입입니다.

## 기술 스택·범위

- **YOLOv8n:** 객체 검출
- **Depth Anything V2:** 단안 깊이 추정
- **TensorFlow.js · ONNX Runtime Web:** 웹 환경 모델 실행 기술
- **Python · Computer Vision:** 프로젝트의 영상 인식 기술 기반
- **HUD·음성 안내:** 선별한 정보를 사용자에게 전달하는 인터페이스

기술명은 확인된 저장소 설명과 공개 포트폴리오를 기준으로 기재했습니다. 특정 기기의 성능이나 모든 실행 경로의 완성을 보증하지 않습니다.

## 프로젝트에서 다루는 문제

- 탐지된 모든 객체를 표시할 때 생기는 정보 과부하
- 객체 검출만으로 판단하기 어려운 거리·접근 징후
- 여러 신호를 HUD 표시 우선순위로 연결하는 판단 흐름

## 현재 단계·기여 표기

**프로토타입 단계**입니다. 공개 정량 평가 수치는 없으며, 실제 도로 안전성·사고 예방 효과·실시간 성능을 검증한 제품으로 소개하지 않습니다. 단안 깊이와 접근 징후는 실제 충돌 위험이나 정확한 거리의 보장이 아닙니다.

원본 작업에는 포크 기반 저장소가 포함되어 있습니다. 이 소개는 프로젝트의 기술 범위를 설명하며, 전체 코드를 단독 창작했다는 의미가 아닙니다. 본 문서는 원본 소스나 내부 자료를 공개하지 않습니다.
